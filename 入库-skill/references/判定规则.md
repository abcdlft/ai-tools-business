# 入库判定规则（用户口径，不要自行改动）

## 1. 数量口径

- **入库数量 = 完整数 + 次品数**（表格 D + E 列）。
- **次品数量 = 入库数量**（两个框都填同一个总数）。
- 表格里的空白格子按 0 算。例：`完整 空 / 次品 1` → 入库 1、次品 1。
- **表格优先于聚水潭申请数**。表格写 1 件、聚水潭申请 2 件，就填 1（部分收货）。这是常态，不是异常。

## 2. 机器可以自动收的（全满足才算）

1. 货号**不含 BBT**，且横杠前的前缀**不是 ZW / HA / HR / QD / RH**；
2. 单号**不带 `母` / `子` 前缀**（子母件交人工）；
2. 聚水潭只返回**一张**售后单、界面只有**一行**商品；
3. 表格总数（D+E）**等于**聚水潭申请数量；
4. 件数 **≤ 2**；
5. 表格 D、E 列都是普通数字，没有「一包加一片」「几片」这类描述。

## 3. 必须交人工的（命中任一即停）

| 情况 | 说明 |
|---|---|
| **BBT 卫生巾** | 表格按「包」记，聚水潭按「件」入。规格 7 包时表 3 包只入 1 件；少件就不入。换算交人工。 |
| **ZW / HA / HR / QD / RH 前缀货号** | 货号横杠 `-` 前面的字母是 `ZW`、`HA`、`HR`、`QD`、`RH` 之一的（如 `ZW-XXXX`、`HA-XXXX`）。只看横杠前那一段、**精确匹配**这几个字母（不是包含），和 BBT 一样列清单交人工。 |
| **一包加一片** | 如「1 包 + 1 片」，无法用整数件表达。 |
| **只有几片 / 一包都没有** | 散片不足一件。 |
| **2 包以上要拆分** | 4 包 → 2+2，3 包 → 2+1 这种拆法判断成本高，交人工。 |
| **一个单号多张售后单** | 界面出现两行及以上，涉及数量分配，交人工。 |
| **子母件（组套主从）** | 单号带 `母DPK` / `子DPK` 前缀（如 `母DPK202853299306`、`子DPK110688180361`）。一组单号对应同一笔退货，收货要成套处理，交人工。 |
| **表格与聚水潭件数差 ≥ 2** | 差异太大，可能是另一张售后单或混装，先问。 |
| **查不到售后单** | 直接跳过，不用管，不用归因。 |

> 「2 包以上就砍掉交给人工」是用户明确定的边界：宁可慢一点，也不要收错库存。

## 4. 判重的唯一依据

**看登记表涂黄**。A~E 已黄 = 已入库，跳过。

不要在本地维护「已收清单」之类的台账 —— 部分收货的售后单在聚水潭里仍然查得到，台账和涂黄会打架；涂黄是人在表格里直接看的那一层，以它为准。

## 5. 涂黄条件

只有**收货成功**（回执含该单号 + `退货成功`）才涂。以下一律不涂：

- 收货失败 / 报错；
- 只做了 `--dry` 演练；
- 交人工的单；
- 查不到售后单的单。

`完整数` 为空的格子涂不涂都行（空单元格写格式后接口不回显），整行 0~4 一起下发即可。

## 6. 话术

- 查不到就说「这单在聚水潭没查到售后单，跳过」。
- 不要写「客服没建单」「客服没审核」这种归因 —— 可能是换货件，也可能是另一个仓库账号下的单。
