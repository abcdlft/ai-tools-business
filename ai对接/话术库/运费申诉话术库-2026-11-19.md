## 一、三条铁律（先看这个）

1. **原因优先**：一级「退货运费」→ 二级「消费者无理由退货，退货运费不应商家承担」；事实不符时可选「其他 / 非以上申诉原因」并在描述写清。禁止的只有带「商品有问题」字样的选项。
2. **金额只填弹窗里的「最多可申诉」**，不是详情页的「已补偿运费金额」。
   - ID-XXXX：已补偿 9.35 → 只能申诉 **2.00**
   - ID-XXXX：已补偿 5.88 → 只能申诉 **0.37**
   - ID-XXXX：未赠送运费 → 却可申诉 **5.10**（平台另扣）
3. **报告只说报告上有的话**：兔小贝山茶花两份报告只有微生物 6 项（菌落总数、大肠菌群、真菌、金黄色葡萄球菌、铜绿假单胞菌、溶血性链球菌），**没有渗透/回渗数据**。

## 二、可直接用的四套模板（均来自真实成功单）

### 模板 A：个人原因 7 天无理由（最通用，4.55 元成功）
```
订单为个人原因7天无理由退货，商品不存在任何质量问题。根据平台规则，无理由退货运费应由消费者
自行承担，平台极速退款时连带运费一并退回商家不认可，请求平台核实，返还商家运费损失。
```

### 模板 B：零沟通、无任何质量凭证（2.00 元成功）
```
买家签收后没有反馈任何商品问题，无质量、破损、漏尿等相关凭证，买家自行发起运费相关退款，
不符合售后规则，我方不认可该运费退款，恳请平台核实驳回。
```

### 模板 C：买家凭证里没有本店商品（0.75 元成功）
```
买家反馈商品漏尿，但提供的凭证图片/视频里没有本店产品，无法证实是本店商品存在漏尿问题，
无有效问题凭证，不属于商家责任，该退货运费不应由商家承担，申请申诉驳回运费诉求。
```

### 模板 D：退货物流停滞、商家未收到退货（6.07 元成功）
```
本订单为退货退款单，平台先行退款给买家。退货物流单号：{单号}，物流仅显示【{网点}揽收】，
后续全程无中转、无发往商家地址的轨迹，我方至今未收到退回商品。退货退款需买家寄回、商家签收
核验后才符合退款条件，请求平台核实物流异常，追回本次先行退款。
```
> 用前必须核对物流轨迹，**包裹已签收的绝对不能用**。

## 四、失败复盘（这 8 条同样值钱）

| 订单 | 金额 | 驳回理由 |
|---|---|---|
| ORD-XXXX-XXXXXX | 1.00 | 经核实，此单商品存在问题，支持用户退货退款 |
| ORD-XXXX-XXXXXX | 1.60 | 经平台核实，订单不符合申诉通过条件 |
| ID-XXXX / ID-XXXX-655 / ID-XXXX / ID-XXXX / ID-XXXX×2 | 0.15–13.10 | — |

**最关键的一条**：ORD-XXXX-XXXXXX 与成功单 ORD-XXXX-XXXXXX 文案**一字不差**，一个成一个败。
结论：运费申诉的成败主要由平台对该单是否「商品存在问题」的既有认定决定，文案只能争取边际分。
所以**先看退款原因和凭证**：只有「无理由 / 无凭证 / 物流异常 / 尺码选择」四类才值得提；
买家已提交有效质量证据（照片、医院诊断）的单，提交基本是白送一次失败记录。

## 五、操作路径（实测 2026-11-19）

1. `https://mms.pinduoduo.com/orders/appeals/aftersale/order` → 页签「**维权申诉**」，靠「申诉项」列筛出「运费申诉」。
2. 行内点「发起申诉」→ **页面内弹窗**（不新开标签）。
3. 两级下拉：点原因框 → 左侧「退货运费 / 其他」→ 点「退货运费」**只展开不选中** → 右侧 4 个二级 → 选第一条。
4. 坑：顶部全局搜索建议浮层（class 含 `mms-header_search_new`）会盖住表单，先 `display:none`。
5. 提交后弹「申诉提交成功」→ 关掉 → 回「申诉记录」按订单号查询，状态应为「待处理」。

敏感词实测会拦：「不能用 / 无法正常使用 / 运费险」。本批三单改用「不应由商家承担 / 未提供照片或视频」全部一次通过。

## 七、2026-11-22 补充：维权申诉页的两个坑

1. **「批量申诉通道」自动弹窗**：本店被判定为平台优质商家，进入维权申诉页会自动弹出批量申诉弹窗（列 4 单货款、只有金额没有原因/凭证）。不关掉它，点单行「发起申诉」会被遮住或点错。
   关闭：批量弹窗内 `[class*=MDL_headerCloseIcon]`，按元素中心坐标点。

2. **「最多可申诉」可能远小于「退货包运费已补偿」**：
   - ORD-XXXX-XXXXXX：已补偿 7.44 元，可申诉仅 **0.10 元**
   - ORD-XXXX-XXXXXX：已补偿 6.46 元，可申诉 **6.15 元**
   差额部分是平台补贴承担的，**一律按弹窗上限填**，按补偿金额填会被拦截。

3. 提交成功后弹「申诉提交成功 / 继续申诉 / 查看申诉记录」，该弹窗会挡住下一次行内点击，必须先关。
